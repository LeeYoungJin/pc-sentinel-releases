# PC Sentinel — 배포 파일

PC Sentinel 은 Windows PC 의 개발 런타임(Node.js, Python, Java, .NET)의 버전·보안 패치·지원 종료 여부를 점검하고
업데이트·정리를 돕는 데스크톱 도구입니다.

이 저장소는 **설치 파일과 앱 자동 업데이트 정보만** 게시합니다. 소스 코드는 포함하지 않습니다.

## 요구 사항

- Windows 10 / 11 (x64)
- WebView2 런타임 (Windows 11 기본 탑재, Windows 10 은 대부분 설치되어 있음)
- Windows PowerShell 5.1 (Windows 기본 탑재)

## 설치

1. [최신 릴리스](../../releases/latest) 에서 `pc-sentinel_<버전>_x64-setup.exe` 를 내려받습니다.
2. 내려받은 파일을 실행합니다.
   - **Windows SmartScreen** 경고("Windows의 PC 보호")가 뜨면 **추가 정보 → 실행** 을 누릅니다.
     코드 서명 인증서 없이 배포되어 게시자가 `알 수 없음` 으로 표시되기 때문입니다.
3. 현재 사용자 계정에 설치되며 관리자 권한은 필요 없습니다. 시작 메뉴의 **PC Sentinel** 로 실행합니다.

> 0.5.0 이하 버전에는 자동 업데이트 기능이 없습니다. 0.6.0 이상을 한 번 직접 설치하면 이후부터 자동으로 안내됩니다.

## 업데이트

- 앱을 시작하면 잠시 뒤 새 버전이 있는지 확인합니다. 새 버전이 있으면 변경 사항과 함께
  **지금 업데이트 / 나중에 / 이 버전 건너뛰기** 중에서 고를 수 있습니다.
- **지금 업데이트** 를 누르면 내려받기 → 서명 검증 → 설치 → 앱 재시작까지 자동으로 진행됩니다.
- 직접 확인하려면 앱 상단의 버전 버튼 → **업데이트 확인** 을 누릅니다.
- 업데이트 후 처음 실행하면 이전 버전 이후 바뀐 내용이 표시됩니다(**도움말 → 변경 내역** 에서 다시 볼 수 있음).
- 런타임 업데이트·정리 작업이 진행 중일 때는 앱 업데이트를 설치하지 않습니다.

### 안전장치

- 설치 파일은 앱에 내장된 공개키로 **서명을 검증한 경우에만** 설치됩니다. 서명이 없거나 다르면 설치하지 않습니다.
- 서명에는 버전이 함께 묶여 있어, 안내한 버전과 다른(예: 이전 버전) 설치 파일은 거부합니다.
- 업데이트는 더 높은 버전으로만 진행되며, 업데이트 확인과 내려받기는 이 저장소의 릴리스(GitHub)에서만 합니다.

## 제거

**설정 → 앱 → 설치된 앱 → PC Sentinel → 제거**.
앱이 만든 백업·캐시(`%LOCALAPPDATA%\pc-sentinel`)는 남으므로 필요 없으면 직접 삭제합니다.

## 문제 해결

| 증상 | 조치 |
|------|------|
| 시작할 때 업데이트 안내가 뜨지 않음 | 시작 시 확인은 네트워크 오류가 나도 조용히 넘어가고, "이 버전 건너뛰기" 한 버전은 다시 묻지 않습니다. 버전 버튼 → **업데이트 확인** 으로 직접 확인하면 오류 내용이 표시됩니다. |
| 회사망·프록시에서 업데이트 확인 실패 | `github.com` 과 GitHub 다운로드 서버(`*.githubusercontent.com`) 접속이 허용되어 있는지 확인합니다. 안 되면 [최신 릴리스](../../releases/latest) 에서 직접 내려받아 덮어 설치합니다. |
| 업데이트가 서명 검증 실패로 중단됨 | 내려받은 파일이 손상되었거나 변조되었을 수 있습니다. 다시 시도하고, 계속되면 직접 설치 파일을 받아 설치합니다. |
| 설치 파일 실행 시 SmartScreen 차단 | **추가 정보 → 실행**. 회사 정책으로 막혀 있으면 IT 담당자에게 문의합니다. |

## 파일 설명

| 파일 | 내용 |
|------|------|
| `pc-sentinel_<버전>_x64-setup.exe` | 설치 파일 |
| `latest.json` | 설치된 앱이 확인하는 최신 버전 정보(버전, 변경 사항, 다운로드 주소, 업데이트 서명) |
