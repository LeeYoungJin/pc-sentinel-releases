# PC Sentinel — 배포 파일

이 저장소는 **PC Sentinel 설치 파일과 앱 자동 업데이트 정보만** 게시합니다. 소스 코드는 포함하지 않습니다.

- 설치: [Releases](../../releases/latest) 에서 `pc-sentinel_<버전>_x64-setup.exe` 를 내려받아 실행
- 자동 업데이트: 설치된 앱이 시작할 때 `latest.json` 을 확인해 새 버전이 있으면 업데이트할지 묻습니다.
  설치 파일은 앱에 내장된 공개키로 서명을 검증한 경우에만 설치됩니다.
